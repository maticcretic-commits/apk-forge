How it works

No build machine, no Android Studio, no terminal.

1

Design in the studio

Pick a source, brand your app, set options — all in this page, with a live phone preview.

2

Connect GitHub

One click, one token. Your build recipe is saved to the repo and the cloud takes over.

3

Cloud builds it

GitHub Actions scaffolds a real Android project, compiles it with Gradle, signs the release.

4

Download & install

Grab the APK from your build history and install it straight onto your phone.

🔑 Getting your GitHub token one-time setup

  1. Open github.com/settings/tokens → Generate new token (classic).
  2. Tick the repo and workflow scopes.
  3. Copy the token and paste it in the Connect GitHub dialog.

Your token is stored only in this browser (localStorage) and is sent only to api.github.com — never anywhere else.
